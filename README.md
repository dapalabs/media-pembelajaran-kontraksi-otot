# Media Pembelajaran Interaktif: Mekanisme Kontraksi Otot 🔬💪

Aplikasi web edukatif interaktif untuk mempelajari fisiologi otot rangka manusia berbasis **Sliding Filament Model** (Model Pergeseran Filamen), dilengkapi dengan visualisasi SVG interaktif dan kuis pemahaman.

---

## 🌟 Fitur Utama

1. **Struktur & Anatomi Otot Rangka:**
   - Visualisasi tingkat organisasi otot (Epimisium, Fasikel, Serat Otot, Miofibril, hingga Sarkomer).
   - Diagram komponen sarkomer (Garis Z, Garis M, Pita A, Pita I, dan Zona H) interaktif.

2. **Simulasi Interaktif Sarkomer (Sliding Filament):**
   - Slider pengontrol kontraksi real-time (Relaksasi hingga Kontraksi Maksimal).
   - Animasi otomatis pergeseran filamen aktin dan miosin.
   - Indikator status perubahan zona sarkomer secara dinamis.

3. **Mekanisme Molekuler & Peran ATP:**
   - 6 tahapan molekuler komprehensif mulai dari impuls saraf, pelepasan ion kalsium ($Ca^{2+}$), pergeseran tropomiosin, pembentukan *cross-bridge*, *power stroke*, hingga relaksasi.

4. **Kuis Uji Pemahaman:**
   - 8 soal latihan pilihan ganda interaktif.
   - Pembahasan langsung seketika (*instant feedback*) untuk setiap jawaban.
   - Perhitungan skor otomatis dan persentase penguasaan materi.

## 🚀 Cara Menjalankan

### Akses Langsung
Cukup buka berkas `index.html` menggunakan peramban web modern apa pun (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). Tidak membutuhkan instalasi dependensi tambahan (100% *client-side* murni berbasis HTML5, CSS3, dan Vanilla JavaScript).
